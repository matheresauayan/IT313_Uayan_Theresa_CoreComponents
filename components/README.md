# Student Directory Viewer

## Problem
This application displays five students who need
academic advising. Users can scroll through the
student cards, search by name, and flag students
for advising.

## Components
- App.js: Main entry point of the application.
- StudentCard.js: Displays one student's photo,
  name, year level, and flag button.
- StudentDirectory.js: Manages student data,
  search, flag status, and the student list.

## React Native Core Components
- View: Organizes the layout.
- Text: Displays text.
- Image: Displays student photos.
- ScrollView: Makes the list scrollable.
- TextInput: Accepts the search query.
- Pressable: Handles the flag button.

## How to Run
1. Install dependencies using npm install.
2. Run npx expo start.
3. Open the application using Expo Go.
